📲 Install Versi iOS & Android

Siap Di-install ke HP Kamu!

Pasang ikon Sambung Cinta langsung di layar utama.

Cara Pasang di HP Android (Full Screen Tanpa Browser):

1. Buka link game ini menggunakan Google Chrome di Android.

2. Ketuk ikon Titik Tiga (⋮) di pojok kanan atas layar.

3. Pilih "Tambahkan ke layar utama" atau "Install aplikasi".

4. Ikon Sambung Cinta 💕 akan muncul di menu HP Android kamu lengkap dengan getaran haptic!

Cara Pasang di iPhone & iPad (iOS Native Mode):

1. Buka link game ini menggunakan browser Safari di iPhone.

2. Ketuk tombol Bagikan / Share (kotak dengan panah ke atas ⬆️) di bagian bawah layar.

3. Geser ke bawah lalu pilih "Tambah ke Layar Utama" (Add to Home Screen).

4. Ketuk Tambah. Game akan berjalan full-screen menyatu dengan Dynamic Island / Notch iPhone!

1. Hosting Gratis via GitHub Pages: Upload file ini sebagai index.html ke repository GitHub, lalu aktifkan Settings > Pages.

2. Compile Jadi File .APK / .IPA (Capacitor):

npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
npx cap init "Sambung Cinta" "com.ldr.sambungcinta" --web-dir=.
npx cap add android && npx cap add ios
